# Jepang: festival musim panas dan acara musiman

Tanggal festival di bawah adalah tanggal tetap tradisional. Jadwal jam acara, rute, dan penjualan kursi berbayar diumumkan setiap tahun; verifikasi dengan google_search "[nama festival] [tahun] schedule" atau kueri bahasa Jepang "[nama] [tahun] 日程". Kembang api bisa diundur bila hujan deras atau dibatalkan karena topan.

Festival musim panas di Aichi: Festival Pelabuhan Nagoya (Hari Laut, Senin ketiga Juli, kembang api malam), Festival Kembang Api Toyota Oiden (akhir Juli), Festival Kembang Api Okazaki (Sabtu pertama Agustus).

Festival di Tokyo lain: Koenji Awa Odori (akhir pekan terakhir Agustus), Asakusa Samba Carnival (Sabtu terakhir Agustus), Kembang Api Itabashi dan Edogawa (awal Agustus), Comiket musim panas di Tokyo Big Sight (pertengahan Agustus).

Festival musik: Fuji Rock Festival (akhir Juli, Naeba, Niigata), Summer Sonic (pertengahan Agustus, Tokyo/Chiba dan Osaka).

## Memilih festival musim panas untuk perjalanan seminggu

- Bila tanggal fleksibel dan ingin dua festival besar: 14–17 Juli di Kyoto (Gion: Yoiyama + parade 17 Juli), lalu Tokyo; atau 24–25 Juli Osaka (Tenjin) disambung Sabtu terakhir Juli Tokyo (Sumida), bila tanggalnya berdekatan.
- Bila perjalanan awal Agustus: Tohoku (Nebuta, Kanto, Tanabata) dengan JR East Pass.
- Bila perjalanan pertengahan Agustus: Awa Odori (12–15 Agustus) dan Gozan no Okuribi (16 Agustus); ingat Obon 13–16 Agustus kereta dan hotel paling padat.
- Festival kecil bon odori dan kembang api lokal terjadi hampir setiap akhir pekan Juli–Agustus di seluruh Jepang; cari dengan kueri "花火大会 [kota] [tahun]".

## Perlengkapan dan etiket festival

- Yukata: sewa di Kyoto atau Asakusa sekitar ¥3.000–6.000 per hari termasuk dipakaikan; lipatan kiri di atas kanan (kanan di atas kiri hanya untuk jenazah). Pakai geta atau sandal yang nyaman.
- Kios makanan (yatai): yakisoba, takoyaki, karaage ¥600–900; kakigori ¥500–800; minuman ¥300–600. Hampir semua hanya tunai; bawa uang receh.
- Bawa kipas, handuk, air minum, alas duduk plastik, kantong sampah sendiri. Toilet umum antre panjang.
- Setelah kembang api, stasiun terdekat bisa antre 30–90 menit; berjalan ke stasiun yang lebih jauh atau tunggu di restoran.
- Banyak festival adalah upacara keagamaan; jangan menghalangi kereta hias (mikoshi, yamaboko).
